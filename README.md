# OldGold

Экономическая стратегия. Земля — в пиксельной манере, здания и жители — в объёмном стиле.

**Запуск:** открыть `index.html` в браузере (Chrome, Edge, Firefox).

## Механики
- **Курьеры ходят только по дорогам**, как вагонетки по рельсам. Здание без дороги к складу не получает доставок, над ним появляется значок дороги.
- **Ширина дороги:** дорога в 2 клетки — две полосы, курьеры разъезжаются без задержек. На узкой встречные протискиваются медленно, попутные ждут.
- **Ферма** сеет пшеницу (зерно) или травы (сено). Что сеять, выбирается галочками в окне фермы.
- **Свинарник:** каждая охапка сена — все подрастающие свиньи растут на треть и рождается поросёнок. После трёх охапок в загоне свиньи 1/3, 2/3 и 3/3. Взрослую везут на бойню.
- **Цепочки:**
  - бойня: колбаса + шкура → дубильня → кожа → кожаный доспех;
  - магия: шахта магических камней → магический круг (мана + обычный камень) → мастерская (посох = доска + мана, мантия = кожа + мана).
- **Удобства:**
  - пауза здания (P) и переход между одинаковыми зданиями ([ ]);
  - кнопка «Обучить», запрет приёма товаров складом;
  - вкладка «Хозяйство» со списком проблем;
  - сохранение (Ctrl+S), загрузка (F9), автосохранение.

## Файлы
- `js/config.js` — товары, профессии, здания (размеры, рецепты, баланс)
- `js/world.js` — карта, рост, дорожные сети
- `js/path.js` — поиск пути (в том числе только по дорогам с объездом занятых клеток)
- `js/entities.js` — здания, жители, движение курьеров
- `js/jobs.js` — поведение жителей (ферма, свинарник, доставка)
- `js/logistics.js` — распределение доставок по дорожным сетям
- `js/buildings.js` — здания: объёмы, крыши, материалы, реквизит
- `js/people.js` — жители: три ракурса, шаг, работа, ноша
- `js/sprites.js`, `js/pixel.js`, `js/terrain.js` — природа, земля, дороги
- `js/icons.js`, `js/render.js`, `js/ui.js`, `js/save.js`, `js/main.js` — иконки, кадр, интерфейс, сохранения, цикл
