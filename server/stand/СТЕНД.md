# Тестовый кооп-стенд OldGold

Второй сервер на том же VPS (151.252.107.75), полностью отдельный от боевого. Нужен, чтобы:
репетировать деплой и обнуление, проверять версии до выкладки и вводить тестовые ники/пароли, не трогая игроков.

| | Боевой | Тест |
|---|---|---|
| Адрес | `wss://151-252-107-75.sslip.io` | `wss://test-151-252-107-75.sslip.io` (игра: https://test-151-252-107-75.sslip.io/) |
| Служба | `oldgold` | `oldgold-test` |
| Порт (только 127.0.0.1) | 8787 | 8788 |
| Код | `/opt/oldgold` | `/opt/oldgold-test` (свой git clone, любая ветка/тег/коммит) |
| Данные | `/var/lib/oldgold` | `/var/lib/oldgold-test` |
| Копии | `/var/backups/oldgold-*` | `/var/backups/oldgold-test-*` (5 последних) |
| Хост (админ) | Lexolas | tester1 |

Общая с боевым точка одна: Caddy (`/etc/caddy/Caddyfile`, блок `test-151-252-107-75.sslip.io`).
Копия Caddyfile до правки: `/etc/caddy/Caddyfile.bak-ДАТА`.

## Игроки
Только синтетические: `tester1…tester6`, пароли случайные, лежат в `/var/lib/oldgold-test/TESTERS.txt` (права 600).
Посмотреть: `ssh … 'cat /var/lib/oldgold-test/TESTERS.txt'`. Боевые аккаунты на тест не копируются.
Пароли меняются при каждом полном сбросе. Можно и зарегистрировать новых игроков прямо в игре.

## Скрипты (в репо `server/stand/`, на VPS — `/root/stand/`)
Все команды из Windows: `ssh -i ~/.ssh/oldgold_vps root@151.252.107.75 '…'` (команды в одинарных кавычках).

- **Залить версию на тест**: `bash /root/stand/test-deploy.sh origin/main` (или тег, коммит, `origin/<ветка>`).
  Перезапускает только при online=0 (`--force` — не ждать), печатает команду отката, версию и журнал.
- **Сбросить тест**: `bash /root/stand/test-reset.sh` — копия, стирает всё, новые тестеры с новыми паролями.
  `--keep-players` — стереть только мир, аккаунты оставить.
- **Репетиция боевого обнуления** (тот же скрипт, что пойдёт на боевой, на тестовых путях):
  `cd /root/stand && SVC=oldgold-test PORT=8788 DATA=/var/lib/oldgold-test CODE=/opt/oldgold-test BACKUP=/var/backups/oldgold-test-rehearsal-$(date +%H%M%S) bash oldgold-reset.sh <коммит>`
  Для честной репетиции сначала поставьте на тест версию боевого: `bash test-deploy.sh $(git -C /opt/oldgold rev-parse HEAD)`.
- **Проверка входа**: `node /root/stand/check-login.js` → «вход ок: tester1 (хост)».
- **Разовая установка** (уже сделана 22.10.2026): `bash /root/stand/test-setup.sh <версия>`.
- После правки скриптов в репо: `scp -i ~/.ssh/oldgold_vps server/stand/* root@151.252.107.75:/root/stand/`.

Журнал: `journalctl -u oldgold-test -n 50`. Состояние: `curl https://test-151-252-107-75.sslip.io/coop-info`.

## Переключатель в клиенте (скрытый)
- Ссылка: `…/OldGold/?stand=test` — включить тест, `?stand=prod` — вернуть боевой. Выбор запоминается на устройстве.
- Без ссылки: Мультиплеер → **7 быстрых нажатий по надписи «Адрес сервера»** (за 3 секунды) — переключает туда-обратно.
- В тестовом режиме над полем адреса оранжевая метка «🧪 ТЕСТОВЫЙ СЕРВЕР». Вход на тесте хранится отдельно
  и не сбивает боевой. Журнал сбоев и статистика в тестовом режиме тоже уходят на тестовый сервер.
- Можно и просто открыть https://test-151-252-107-75.sslip.io/ — стенд сам раздаёт игру своей версии.

## Убрать стенд полностью
`systemctl disable --now oldgold-test; rm /etc/systemd/system/oldgold-test.service; systemctl daemon-reload;`
вернуть Caddyfile из `/etc/caddy/Caddyfile.bak-ДАТА`, `caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy`;
`rm -rf /opt/oldgold-test /var/lib/oldgold-test /var/backups/oldgold-test-* /root/stand`.

## Нельзя
- Пускать на тест копию боевых данных (там хеши паролей и герои настоящих игроков).
- Ботов `server/stress.js` можно гонять только на тесте при online=0 и после этого делать `test-reset.sh`.
  Сервер маленький (2 ГБ на оба мира), у теста лимит памяти 600 МБ.
