# Личное Android-приложение OldGold

APK-«обёртка» (Capacitor) без публикации в Google Play: открывает игру с сайта
https://xxxlexolasxxx.github.io/OldGold/ — поэтому **любое обновление игры подтягивается само**,
пересобирать APK не нужно. Кооп (wss://151-252-107-75.sslip.io) работает как в браузере: страница https, сокет wss — mixed content нет, своего CSP у игры нет.

## Установка на телефон (по шагам)
1. Возьмите файл `mobile\oldgold-personal-debug.apk` (≈4 МБ).
2. Передайте на телефон одним из способов:
   - **Кабель USB:** подключите телефон, на нём выберите «Передача файлов», перетащите APK в папку «Download».
   - **Google Диск:** загрузите APK на диск с компьютера, на телефоне откройте Диск → файл → «Скачать».
3. На телефоне откройте файл (через «Файлы» → Download). Android спросит разрешение:
   «Установка из неизвестных источников» — нажмите «Настройки» и включите переключатель для того приложения,
   из которого открываете файл («Файлы», «Chrome» или «Диск»). Вернитесь назад и нажмите «Установить».
4. Если Play Protect предупреждает «неизвестный разработчик» — «Всё равно установить» (APK ваш собственный).
5. Значок OldGold появится в списке приложений. Первый запуск требует интернет.
После установки разрешение «неизвестные источники» можно выключить обратно.

## Обновления
- Игра — само, при каждом запуске (грузится с сайта; кэш держится не дольше ~10 минут + service worker сети отдаёт приоритет).
- Пересобирать APK нужно только если меняется сама обёртка (иконка, адрес сайта, поведение окна).
  Новый APK ставится поверх старого (applicationId тот же, подпись debug-ключа та же на этом компьютере).
- Без сети показывается локальный экран «Нет связи с сайтом» с кнопкой «Повторить» (само повторяет при появлении сети).

## Что внутри
- `mobile/capacitor.config.json` — `server.url` на сайт, `cleartext: false`, `errorPath: offline.html`.
- `mobile/shell/` — локальные страницы (`offline.html`, запасной `index.html`).
- `mobile/android/.../MainActivity.java` — полноэкранный режим (скрыты системные панели, свайп от края показывает их), без «резинки» прокрутки,
  звук без жеста-блокировки, экран не гаснет, вырез камеры закрашен.
- Иконка и сплэш — из `icons/` (`node mobile/apply-icons.js`, нужны `desktop/node_modules`).

## Белая полоса сверху (вертикаль)
Capacitor 8 при targetSdk 35+ может отодвинуть WebView от строки состояния и выреза камеры; поле над игрой — фон окна
и родителей WebView. `MainActivity` красит их в #1a130d (окно — с 19.10 21:48, родителей WebView — с 22.10).
APK `mobile\oldgold-personal-debug.apk` (versionCode 1) собран 19.10 в 21:43, до первой правки, — в нём полоса белая.
Исправленный — `mobile\oldgold-personal-debug-v2.apk` (versionCode 2, «1.1», 22.10): ставится поверх старого, подпись
та же (debug.keystore, SHA-256 05e301f8…6e8b), сохранения остаются. В `capacitor.config.json` добавлено
`SystemBars.initialViewportFitValueHint: "cover"`: на WebView 140+ игра сразу рисуется под вырезом, а HUD отступает
по `env(safe-area-inset-top)`; на старых WebView Capacitor отодвигает игру, и поле — тёмное.

## Пересборка (Windows)
Нужны JDK 21 и Android SDK (у автора — `D:\android-sdk\jdk\...` и `D:\android-sdk\sdk`).
Путь проекта должен быть латиницей: в `D:\для игры\…` Gradle собирать отказывается — скопируйте `mobile\`
(вместе с node_modules) например в `D:\og-apk-build\mobile` и собирайте там. Каждая сборка для установки поверх —
versionCode +1 в `android/app/build.gradle`, applicationId не менять, подпись тем же debug.keystore.
```
cd mobile && npm ci
npx cap sync android
cd android
# создать local.properties: sdk.dir=D\:/android-sdk/sdk   (прямые слэши: обратные в .properties съедаются)
set JAVA_HOME=D:\android-sdk\jdk\jdk-21.0.12.1+1
gradlew.bat assembleDebug
```
Результат: `mobile\android\app\build\outputs\apk\debug\app-debug.apk` → скопировать как `mobile\oldgold-personal-debug-vN.apk`.
APK в git не коммитится (`.gitignore`).

## Проверено в эмуляторе (Pixel 6, Android 14, WebView 113, 19.10.2026)
Загрузка с сайта, новая партия, жесты (перетаскивание, щипок), звук, сворачивание/возврат (без перезагрузки, звук в фоне на паузе),
поворот экрана, кооп (wss открывается, вход в «Общую деревню»), без сети — игра из кэша service worker, при первом запуске без сети —
экран «Нет связи» и автоматический вход в игру, когда сеть появилась.
Отладка: debug-сборка разрешает chrome://inspect (WebView), `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`.
Эмулятор: `D:\android-sdk\sdk\emulator\emulator.exe -avd pix` (нужны SVM в BIOS и Windows Hypervisor Platform).
