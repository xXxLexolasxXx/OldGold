# Статистика одиночной игры (воронка)

Всё идёт через GoatCounter (`lexolas.goatcounter.com`), код — `js/stats.js`, вызов `track(имя, заголовок)`.
Личных данных нет: ни ника героя, ни имён профилей, ни паролей, ни ников коопа. Cookie нет.
На localhost события не отправляются. Каждое событие шлётся **не чаще одного раза за запуск страницы**,
поэтому число в GoatCounter ≈ число игроков/запусков, дошедших до момента.

## Как смотреть
GoatCounter → сайт → вкладка **Events** (список событий `event/<имя>` с числом уникальных посетителей и хитов).
Воронка — это сравнение чисел по порядку ниже: делите «следующий шаг / предыдущий». Фильтр по дате — вверху.

## Воронка по порядку
| Событие | Что значит |
|---|---|
| (страница) | открыли игру — просто посещения |
| `start-desktop` / `start-mobile` | игра запущена (ПК / телефон) |
| `menu-continue` / `menu-new` / `menu-mp` / `menu-help` | кнопки стартового меню |
| `tut-start` | показалось обучение (новичок); `tut-seen-before` — обучение уже проходили раньше |
| `tut-step-01` … `tut-step-16` | дошёл до шага N обучения |
| `tut-ok-01` … | выполнил задание шага N |
| `tut-skip-NN` | закрыл («✕») обучение на шаге NN — тут люди бросают/пропускают |
| `tut-done` | прошёл обучение до конца |
| `place-1` / `built-1`, `built-5`, `built-10`, `built-20` | заложил / достроил первое, 5-е, 10-е, 20-е здание |
| `night-1` | дожил до первого вечера; `night-seen` — до первой ночи |
| `night-long` | дожил до первой долгой (5-й) ночи |
| `lost-1` | потерял первого гнома |
| `graveyard` | построено кладбище |
| `neu-attack` | герой впервые напал на лесных нейтралов (логова фей, лешего, кабанов, моховиков) |
| `neu-kill`, `neu-kill-fairy` / `-leshy` / `-boar` / `-spore` | первая победа над лесным жителем (всего / по виду) |
| `neu-lose` | герой проиграл бой лесному жителю |
| `profile-open`, `ach-open` | открыл «Профиль и ачивки» / список ачивок |
| `ach-first` | получил хоть одну ачивку; `ach-<id>` — конкретную (id из `ACHS` в `js/profile.js`) |
| `coop-join` | зашёл в кооп (успешное подключение) |
| `play-1m`, `5m`, `15m`, `30m`, `60m` | время сессии (только пока игра не на паузе и вкладка открыта) |
| `return-any`, `return-d1`, `return-d2-7`, `return-d8plus` | вернулся: в браузере хранится только дата первого захода (`oldgold-visit`), наружу уходит лишь категория |
| `menu-save/load/loadauto/new/help` | кнопки игрового меню (старые события) |

Типичные вопросы: «где бросают обучение» — сравните `tut-step-NN` по порядку и `tut-skip-NN`;
«доходят ли до ночи» — `built-1` → `night-seen` → `night-long`; «возвращаются» — `return-d1` / `start-*`.

## Слои статистики
1. **GoatCounter** (выше) — события `event/<имя>`, смотреть во вкладке Events.
2. **Свой счётчик на VPS** (`server/events.js`, `POST /e`) — тот же набор событий, но со случайным id клиента, поэтому
   считается настоящая воронка «сколько *разных* игроков дошло до N» и возвращаемость (D1/D7). Сводка: `node server/events.js`
   или `/stats?key=…` (см. `server/DEPLOY.md`). Данные: `/var/lib/oldgold/events.json`. Ника/IP/имён нет.
3. **Локально в браузере**: `oldgold-funnel` (что игрок прошёл и когда; в консоли `statsFunnel()`), `oldgold-pending`
   (очередь на отправку: копится офлайн и уходит, когда сервер доступен; `fetch` с таймаутом 5 с, при сбое повтор с паузой,
   при закрытии вкладки — `sendBeacon`), `oldgold-cid` (случайный id), `oldgold-visit` (даты заходов).
На localhost (и file://) наружу ничего не отправляется — только локальная воронка.

## Ограничения GoatCounter
GoatCounter не строит настоящую воронку по человеку (не знает, один ли игрок прошёл шаги) — для этого слой 2.
