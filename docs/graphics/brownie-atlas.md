# Домовой: модель и готовый атлас

Эталон Леший v4, детальные кисти по утверждённому forest-hand-detail. Только Домовой: пять исходных видов и три отражения, меньшая голова, пропорциональный корпус, цельные плечо–локоть–кисть. Стопы и нижняя часть тела неподвижны в выглядывании; верх наклоняется целиком вокруг таза не более3.2градуса. Нативные5секунд pk и alpha, контроллер brownieTick и сохранения сохранены.

Атлас assets/fantasy/forest-neutrals-v4/brownie-peek-v1.png:960x896,8рядов по S/SE/E/NE/N/NW/W/SW,10колонок i0/peek0…peek8, ячейка96x112. Одна ячейка48x56мира, якорь24,52, шаг0.5. Все80 RGBA кадров запечены из штатного рендера, композиция и PNG decode проверены поканально. Нативный Домовой используетS; остальные виды доступны полным моделям и портрету.

Обычная загрузка использует атлас вместо декодирования/разделения тяжёлого brownie-pixel.png. Нет синхронного prewarm поз. Исходный генератор и PNG сохранены; A.loadBrownieSource()/brownieSourceFrame() загружаются только явным инструментом или при недоступности atlas. Сбой atlas не выключает другие виды лесного реестра.

Пекарня и мельница — два штатных жилья. Графические опоры привязаны к порогу утверждённых PNG по двум отдельным landmarks, через эффективный _artBox/поворот/уровень, fallback к fyDoor. Общая позиция не сдвигается во время peek. Молоко и глаза следуют той же графической опоре. Рисунок зданий и механика не меняются.

Для изменения модели сначала править brownie cfg/руки/ветвь paint, затем выполнить:

node tools/art/export-brownie-atlas.cjs <корень игры> <папка результата>

Нужен playwright-core (PW_CORE может указать установленный пакет) и Chrome. Инструмент открывает штатный index с контрольным сохранением, явно загружает авторский источник, снимает80 кадров и сравнивает RGBA после композиции/PNG decode. Он сохраняет PNG/сырые RGBA/manifest в папку результата, не подменяет одобренный asset автоматически. После художественной сверки перенести PNG и, при изменении геометрии источника, brownieModelMeta из sourceModels manifest. Нельзя менять anchors/grid ради подгонки картинки.

Проверки: обычный index ПК/mobile; native bakery/mill×уровни1/2/3×повороты0/1/2; полный5сек peek и рабочие лопасти;9поз×8направлений с неизменными пикселями стоп; точныйRGBA source→atlas→HTTP frame; raw-source request отсутствует при нормальном старте; fallback при блокировке atlas; cold/warm и общий test:render на точном выпуске. Новый PNG нужно включить в offline cache ведущей.
