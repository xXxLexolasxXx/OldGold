# Кабан и лесные убежища: исправление опор и подходов

База: `3bdf998cef97624d8cde63e0fb69d682e7fe636c`. Владелец: ветка boar-followup. Изменения ограничены `fantasy-boar-guard-v8.js`; принятые растры, игровой масштаб, AI, карта дорог, сохранения и длительности действий сохранены.

- У кабана опора всех двенадцати фаз шага берётся из принятого нового растра. Ранее w3/w9 поднимали её на один пиксель буфера (0,5 мирового пикселя).
- Лёжка и нора броненосца соединяют свою южную тропу с уже существующей дорогой в клетке `(x,y+2)`. Кромка стабильна по координатам; над местом соединения сохраняется точная каменная поверхность дороги.
- У обоих убежищ выделены передние корни/свод. Проём остаётся открытым; передние маски состоят только из пикселей соответствующего принятого живого или разрушенного состояния. Шесть масок строятся один раз до игрового кадра.

Фокусная проверка: `node output/fantasy/boar-followup-20261119/verify.cjs` из исходного каталога feod. Стенд использует полный production index отдельного клона, штатные `neuMove`, `neuFrame`, `neuDrawList`, `render` и загруженное игровое сохранение. ПК 1280×800/DPR1, мобильный профиль 390×844/DPR3/touch. Снимки и `game-report.json` лежат рядом со стендом.

Результаты на обоих профилях: 744 комбинации ракурса и кадра без пустот/обрезки, опора 99/99 во всех 60 уникальных кадрах шага, проход каждого жильца на 2,166 клетки, правильная глубина до/после порога, шесть передних масок без добавленных невидимых пикселей, состояния 0/1/d, ноль ошибок страницы и загрузки ассетов. `npm run check` проходит. Независимая сверка ведущей и ветки гномтавров: непрерывность стыка, передний свод и свободный передний проход.

Глобальный render-budget и итоговая сборка проверяются ведущей общей волной. Фокусная сцена подтверждает проход по доступной земле; новые маршруты AI не добавлялись.
