## 1. Лицензии и происхождение ассетов — ✅
- **Графика:** вся процедурная (canvas), в `js/*.js`; растровых игровых ассетов в репозитории нет. Растры есть только в `promo/` (скриншоты/логотипы самой игры) и `icons/` (получены из `favicon.svg`).
- **Звук и музыка:** синтез Web Audio (`js/sound/*`), файлов `.mp3/.ogg/.wav` нет.
- **Шрифты:** Kurale и Ruslan Display — SIL Open Font License 1.1 (Google Fonts), лежат в `fonts/`. OFL разрешает коммерческое распространение и встраивание в игру; нельзя продавать шрифт отдельно, нужно сохранить копирайт-заметку. 👤/⬜ положить полные тексты OFL и авторов в файл «Лицензии» внутри приложения (сейчас `fonts/LICENSE.txt` — одна строка; надо заменить на полный текст OFL с копирайтами из метаданных шрифтов).
- **Библиотеки:** в игре нет внешних JS-библиотек. Внешний скрипт один — GoatCounter (`gc.zgo.at`), только в браузерной версии; в сборках приложений он вырезается.
- **KaM/HoMM:** упоминания были только в комментарии `js/buildings.js` и в имени функции `tuftHoMM` — переименовано (`tuftPebbles`). Ассетов и текстов оттуда нет. Остаётся: общие фэнтези-существа (феи, леший, скелеты) — не охраняемые образы.
- Инструменты обёрток (Electron — MIT, Capacitor — MIT, esbuild — MIT, sharp — Apache-2.0) в игру не входят, но Electron/Chromium требует включить свои лицензии в сборку (`LICENSES.chromium.html` — electron-builder кладёт сам).
- ⬜ Папки `D:\для игры\Knights and Merchants`, `здания`, картинки-референсы лежат **вне** репозитория; в сборки не попадают. Убедитесь, что они не загружаются никуда в Steam-депо.

## 3. Обёртки
### Десктоп (Steam) — `desktop/` 🟡
- Electron 33, окно с локальной игрой, F11 — полный экран, внешние ссылки открываются в браузере ОС, одиночный экземпляр.
- `npm install && npm run start` — собрать www и запустить; `npm run smoke` — проверка «игра загрузилась без ошибок» (результат: `Game: object, canvas: true, errors: 0`, версия 0.10.1).
- `npm run dist` — electron-builder (Windows dir, Mac, Linux AppImage) — **не запускал** (долго и под Mac нужен Mac), конфиг в `package.json`.
- **Steamworks** (`desktop/steam.js`): ачивки — игра вызывает `OldGoldNative.achievement(id)` при получении (хук в `js/profile.js`); сейчас пишется в `achievements.json`, при `STEAM_APP_ID` и пакете `steamworks.js` уйдёт в Steam. Облачные сохранения: `js/native.js` дублирует `feod.save.*` в папку `cloud/`, `preload.js` подтягивает новее. 👤 App ID, список ачивок в партнёрском кабинете (API-имена `ACH_<ID>`), включить Steam Cloud на 1–2 МБ.
- ⬜ CSP не задан (Electron предупреждает); игра использует inline-обработчики — потребует правки перед релизом. ⬜ Подпись кода Windows/Mac notarization — 👤.
- Tauri не выбирал: игра тяжёлая на canvas и звук, нужен единый движок на всех ОС; Electron предсказуемее для Steam.

### Мобильные — `mobile/` 🟡
- Capacitor 8: `appId ru.oldgold.game` (👤 поменять на свой домен/идентификатор до первой загрузки, потом менять нельзя), проекты `android/` и `ios/` созданы, `www/` синхронизируется (`npm run sync`), иконки/сплэш применены (`node apply-icons.js`).
- Плагины: App, StatusBar, SplashScreen. `js/native.js` скрывает статус-бар на устройстве.
- **Собрать здесь нельзя:** нет JDK и Android SDK (APK: Android Studio → `npm run android`); iOS — только Xcode на Mac (`npm run ios`) и аккаунт Apple.
- Проверить на устройстве: аудио после разблокировки жестом, сохранения (WebView может чистить хранилище при нехватке места — подумать про Capacitor Preferences), безопасные зоны, кнопка «Назад» (Android), производительность на слабых телефонах (в игре есть `perf.js`).

## 4. Офлайн, размер, кэш
- ✅ **Service worker** `sw.js` + `js/pwa.js`: предзагрузка index.html, всех js/css, шрифтов и иконок; сеть в приоритете (6 с), при обрыве — кэш. Работает только по https на реальном домене (на localhost и в приложениях выключен). Кооператив, `/e`, чужие домены не кэшируются. Версия кэша — константа `CACHE` в `sw.js` (поднимать при ломающих изменениях; обычные обновления подхватываются сетью).
- ✅ **Размер:** js+css 2,48 МБ → 1,73 МБ минифицировано → 0,56 МБ gzip; шрифты 0,28 МБ. Итого сборка приложения ≈ 2 МБ.
- ✅ **Сервер кооператива** (`server/server.js`): gzip для html/js/css/svg/ttf, `max-age=1 неделя` для шрифтов/png, остальное `no-cache`; закрыт доступ к `desktop/`, `mobile/`. ⬜ нужен деплой на VPS (не делал).
- ⬜ GitHub Pages: свои заголовки задать нельзя (сам отдаёт gzip и 10 мин кэша) — приемлемо.
- ⬜ Ленивая загрузка: 85 глобальных скриптов без модулей, порядок важен; безопасно отложить можно только тяжёлые необязательные (`pixelart*.js`, сюжет, нейтралы) после переработки зависимостей. Для приложений загрузка локальная — не критично; пока не делал. В браузере выигрыш даёт gzip (0,56 МБ).
- ⬜ Единый бандл/версионирование `?v=` — не требуется для приложений; для веба SW сеть-в-приоритете решает залипание кэша.

## 6. Монетизация и цена — только варианты, не решено
Предварительное решение пользователя: **Steam $9,99 база**, регион России/СНГ ~500 ₽ (сверить с рекомендациями региональных цен Steam); **мобильные: бесплатно с демо + разовая покупка $3,99–4,99**.
Варианты и вопросы:
- Steam: премиум-цена; демо на Steam (отдельная демо-версия — хороший вишлист-драйвер); DLC позже; скидки на запуске −10–20%.
- Мобильные: демо-ограничение (например, время до 1-й/2-й ночи или без героя/кооператива) + разовая разблокировка (non-consumable IAP). **Нужна реализация покупки:** Google Play Billing / StoreKit через плагин Capacitor — потребует ключей аккаунтов; сейчас не сделано, «демо» в игре не реализовано.
- Альтернативы: платная без демо ($2,99–3,99), реклама (не рекомендую: конфликт с политикой «без рекламы»).
- 👤 **Вопрос: оплата и выплаты разработчику из РФ.** Нужно проверить актуальные условия: регистрация в Steamworks (налоговые/банковские данные), выплаты Steam, Apple Developer Program ($99/год, оплата картой и приём выплат), Google Play Console ($25 и выплаты), доступные платёжные каналы для вашей страны/резидентства, возможность самозанятого/ИП/юрлица в другой юрисдикции, налоги. Здесь не проверялось и не решалось.
