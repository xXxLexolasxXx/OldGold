# Незавершённая графика — сохранение на конец дня

Эта ветка — резервный рабочий снимок. GitHub Pages публикуется из `main`, где находится проверенная игра 0.11.99. Модули новых животных и лесных нейтралов здесь не подключены к index.

Сохранены новые наземные звери, птицы, водная и мелкая фауна, волшебные звери, лесные нейтралы, directional-прототипы тролля/мирного голема, гоблинов и жаболюдов, исходные изображения и QA/handoff. Копии отчётов фиксируют состояние на момент сохранения; промоматериалы 0.12.0 остаются черновиками.

Двор Малгора требует исправить размер: поздняя cold-native проверка выявила увеличение на 14–31%. В main он отключён по умолчанию (`courtPreview=1` только для проверки). Остальная нежить ждёт полного directional-прохода. Тролль/мирный голем ещё требуют повторной проверки масштаба после последней калибровки и всех слоёв/сезонов.

Первый набор восьми наземных животных прошёл 984 основных и 560 дополнительных случаев; несовпадение horse/cart после вытеснения из кэша исправлено. До подключения остаются реальные 1:1 сравнения, грузы, наслоения и production desktop/mobile. Водная и мелкая фауна имеют известные незакрытые вопросы масштаба. Полные ограничения перечислены в handoff каждой группы.

Пользователь позднее прямо попросил птичью ветку продолжать: она работает дальше. Этот коммит сохраняет её промежуточное состояние и не означает завершение птиц. Последующие изменения могут остаться в рабочей папке после данного снимка.

Ничего из этого каталога не добавлять в live только на основании существования файлов или старого PASS. При продолжении читать GRAPHICS_RULES.md, затем самый поздний handoff; реестр и границы владельцев сохраняются. Прямое указание пользователя отменяет старый запрет переноса гоблинов: готовые модели разрешено переносить после интеграционной проверки.
