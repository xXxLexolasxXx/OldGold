# Малая фауна — HOLD, не подключать и не публиковать

Последнее прямое уточнение пользователя исключило живность из дальнейшего редизайна. Перечитаны актуальные `GRAPHICS_RULES.md`, `GRAPHICS_COORDINATION.md`, принят реестр ведущей. Вся эта группа — животные; разрешённых не-животных видов внутри неё нет. Художественные правки и новые длинные прогоны остановлены сразу после уведомления. Сохранённое не удалено.

По отдельному прямому запросу пользователя «доделай все и комить» сохраняется **WIP snapshot** на отдельной HOLD-ветке, без изменения общего git-индекса, текущей ветки, без push и без live-публикации. Своё новое автоподключение из index сняла; index вернулся к прежнему содержимому. Это не откат сохранённого модуля/ассетов и не изменение ранее опубликованных животных.

Для snapshot используется отдельный GIT_INDEX_FILE и новая HOLD-ссылка через commit-tree; текущие HEAD и общий index проверяются по SHA до/после. Автор локального автоматического snapshot — `Codex <codex@local.invalid>` через параметры единственной команды, потому что user identity не настроена; глобальные/repo настройки пользователя не меняются.

## Состояние проверки

До HOLD выполнены full-index desktop/mobile прогоны без повторной инъекции: 1704 сочетания на профиль; 0 пустых кадров, 0 касаний края NA, 0 мутаций входных entities, ограниченный кэш и одна загрузка адаптера. Эти прогоны относятся к промежуточной версии до последней правки контура хвостового плавника тритона; **их нельзя переносить как финальный PASS на текущий SHA**.

Отдельная проверка 378 анатомических head/lantern/ground landmarks дала максимальную погрешность E `8.88e-16`; высшая точка маски не выдаётся за точку головы. Cold-native и actual 1:1 листы сохранены. Последний завершившийся 1:1 прогон (`worldscale-audit.json`, `worldscale-actual-and-enlarged.png`) включает последнюю правку: frog E 11×7 совпадает с cold native, worm 7×4 и bee 3×3 также; у тритона E 40×16 против 40×17, у фонарика 35×23 против 37×24. Остальные проекции имеют естественно разные ширины, без независимого растягивания каждой колонки. Все промежуточные отчёты и изображения сохранены, устаревшие обзоры/GIF не являются доказательством текущего SHA.

## Технические границы

Девять фактических видов и native пути — `ROSTER.md`. Модуль использует native frame selectors, WeakMap/context, LRU ≤768 entries /16 MiB, проектные assets, ready/errors и native fallback. NA_SPEC, физические footprint/опоры, длительности, AI и save-поля не менялись. Прозрачный presentation-буфер тритона расширен вниз на 2 world pixels для четвертных ракурсов, ax/ay и мировой масштаб не менялись. Верёвка/волокуша/метки/наружный свет сохранены из native fwDraw, включая его боковые anchors. Положение головы и внутреннего фонарика сопоставлено с реальными native анатомическими точками, а не bbox. Калибровка каждой native позы frog одна на все пять авторских видов.

## Что НЕ готово

- Нет конкретного независимого визуального review и приёмки ведущей на текущем SHA. Соответствие принятому pixel-art эталону не объявлено состоявшимся.
- Последняя версия не получила повторный полный QA/обновлённый GIF после последней небольшой правки, потому что живность остановлена.
- Не включать адаптер в index/SW, не cherry-pick в live и не возобновлять животных без нового прямого разрешения пользователя.
- `/coop-info` 404 в старых игровых QA — штатный probe на статическом сервере, не спрятанный заглушкой. Физический телефон/performance не проверены.

Ведущая и координирующая ветка уведомляются настоящими сообщениями с manifest/commit SHA. При возможном будущем возобновлении сначала применить трёхшаговую координацию из GRAPHICS_COORDINATION.md: зафиксированный одобренный эталон/SHA → один полный образец и независимые замечания → review того же финального SHA перед готовностью. Этот HOLD-документ имеет приоритет над ранними HANDOFF/DAY_END/SELF_AUDIT формулировками.
