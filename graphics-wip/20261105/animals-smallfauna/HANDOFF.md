## Состав и дизайн

Точный фактический реестр с путями, числом кадров и опорами — `ROSTER.md`. Девять отдельных presentation-моделей: лягушка; бабочка с пятью native цветами; мелкий мотылёк у огня; пчела; светлячок; дождевой червь; болотная улитка; мотылёк-фонарик; тритон.

Лягушка: встроенный imagegen, прозрачный проектный atlas 5 самостоятельных видов × 7 полных тел/поз. Атлас не подменяет голову на старом теле. Sprite cells выделены по alpha, описаны явными прямоугольниками. В игре сводятся nearest-neighbor на прежний 11/12×5/6/7 world-pixel контракт, backing ×2; alpha бинарная. Левые виды зеркалят только соответствующие правые ¾ / профиль, спина — отдельная.

Остальная фауна: заново написанная native pixel geometry на шаге 0,5 world pixel, объёмные поверхности, отдельные крыловые контуры профиля / ¾, четыре лапы у тритона, непрерывная нога моллюска без выдуманных лап, шестиногая микроанатомия насекомых. У червя нет нарисованных глаз или лап. Сохранены красные жаберные веточки реальной native модели тритона. У задних поверхностей нет лиц и глаз; дальние/ближние лапы выбираются по глубине для каждого вида.

У червя нет native перемещения/цели/ориентации, поэтому в игре сохраняется исходный профиль. Ручные восемь видов доступны для проверки его симметричной анатомии, но новый AI поворотов червю не добавлялся. Светлячки и стайные мотыльки получают вид из производной их существующей орбиты; остальные — из фактического смещения, затем native target/face. Память направления только WeakMap.

## Контракт

- Обёрнуты drawFrog, drawWorm, drawButterfly, drawFireflies, beDrawBees; только ветка moth в wlDraw; только snail/newt/moth в fwDraw и naFrame. Гуманоиды ft*, armad, волки, BoarGuardian и другие виды не перехватываются.
- Родные селекторы frogFrame / fwFrame / naIdleFr / naWalkFr / naWinFr и pose tables не менялись. Никаких новых игровых полей, AI, таймингов, footprint или сериализуемого состояния.
- Контекст направления fwDraw → naFrame transient, восстанавливается через finally. Имеющийся native face-flip компенсируется, чтобы получить нужный мировой вид без двойного зеркала.
- Верёвка, волокуша, груз, ошейник и ночной свет рисуются исходным fwDraw. Его anchors сохранены буквально. Ограничение native: боковая волокуша / привязь остаётся на прежних экранных точках при новых передних/задних видах; новые anchors для неё не вводились. Порядок: груз/верёвка до нового тела, свет/ошейник после тела.
- Кэш: вид + view / mirror + нормализованный native state/frame (для крошечных циклов 12/4/2). Raw timestamps не являются ключами. LRU ≤768 entries и ≤16 MiB RGBA. Исходный atlas — фиксированный отдельный loaded asset 1060×1484 RGBA, не растущий кэш.
- `FantasyPublishedSmallfauna.readyPromise` → boolean, `.ready`, `.errors`, `.requiredAssets`, `.stats()`, `.enabled`, `.clear()`, `.preview(kind,fr,d,col)`. До ready / при ошибке / при enabled=false — native fallback. Повторное подключение защищено idempotent guard.
- frogSprite остаётся legacy native getter; фактический единственный drawFrog-path использует новый body atlas. Портретного getter для этой крошечной фауны в рабочем реестре не найдено; общий naFrame вне fwDraw возвращает тот же новый body в профиле, без отдельного дизайна головы.
