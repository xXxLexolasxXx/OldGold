## Известные незавершённые места

1. Нет полного renderer/state пакета всех назначенных видов. Нельзя подключать текущий модуль как готовый выпуск птиц.
2. Нет финальной проверки реального общего игрового кадра у pinned школы, независимого review на текущем SHA и приёмки ведущей. Эталон материалов прочитан: `court-bodies-v4-pixel.png` SHA `479a014c…`; его неверный prototype scale не использовался как масштабный эталон. Школа соответствует pinned SHA `4fd9c9f7…`.
3. Нет production-index проверки после подключения ведущей без инъекции. Текущие browser tests загружали настоящий production index, затем добавляли модуль в изолированном harness. Сам index не изменён.
4. Требуют проверки крайние/промежуточные henbuff growth/kick, ближние/дальние ноги, швы нового goose attack-композита, вода, бантик/груз duck, окаймления и grip contact совы. Дополнительные шанки совы могут потребовать удаления/уточнения после нового foot-aligned атласа; нельзя выдавать старый grab PASS за этот новый слой.
5. Три raw-пичужьих листа не прошли первоначальное ожидание числа ячеек: brown ground=21 вместо22, brown flight=11 вместо12, winter ground=21 вместо22. `atlas-inspection.json` фиксирует FAIL. Возможное соответствие реальным повторяющимся native WL_FLAP8/idle/react позам ещё не оформлено и не проверено; не снижать expected count ради ложного PASS.
6. У raw fRaven/bats/морских specials остаются анатомические, фазовые, layer и alpha/scale проверки. Ни одна новая генерация сама по себе не является готовым набором.
7. Ранние `owl-before-after.png`, `owl-directional.png`, `owl-native-animation.webm` — история предыдущих стадий. Галерея в старом `qa-animation.cjs` ещё использует прямой drawImage и не учитывает поздний padded buffer; для текущего масштаба использовать `scale-audit.cjs`/`drawFrame`, а не этот старый визуальный лист.
8. У native `fyBlit` семь параметров, поэтому лишний восьмой `.9` в старом goldGooseDraw игнорируется. Новый draw сохраняет фактический scale1; ошибочную прежнюю заметку о .9 не использовать как контракт.

## Как сохранять и возобновлять

Активный упаковщик — `pack-atlases-v3.cjs` с `pack-plan.json`; его inputs — сохранённые PNG/JSON в `candidates/`. Сначала изучить `worldScale`, `renderBox`, `padding` и current `drawFrame`; не возвращаться к индивидуальному fit-to-canvas. `pack-atlases.cjs`, `pack-atlases-v2.cjs`, `compile-current.cjs` и одноразовые edit-helper .py сохранены только как история, **не запускать их повторно поверх текущего состояния**.

Новые запуски/семейства — только после нового прямого поручения пользователя. В shared clone не коммитить параллельно ведущей. Не удалять WIP, не выполнять reset/clean и не подключать его к live автоматически.

Для растров использован встроенный `image_gen`, не CLI/API fallback. Сохранены raw sources, `prompts-corrections.json` и `prompts-native-specials.json`; это промпты незавершённых последних исправлений, не художественная приёмка.
