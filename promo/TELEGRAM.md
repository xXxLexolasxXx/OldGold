> Браузерная игра про деревню лесных гномов: стройка, хозяйство, ночная нечисть и кладбище, которое растёт само. Без установки — открыл и играй, можно с телефона и вдвоём-втроём в общей деревне. Тут: новости, байки и скриншоты.

(≈250 знаков; перед вставкой проверить счётчик Telegram.)

## 6. Рубрики и идеи на потом

- «Байка из журнала» — одна смешная запись игрового журнала + скрин.
- «Гном недели» — один гном крупным планом (портреты из `portraitURL`).
- «Опрос» — чего не хватает деревне: пивоварни, больших ночей, нового класса.
- «Было / стало» — сравнение старой и новой графики зданий (папка `_before/`).
- Видео- и GIF-версии постов (ночь, голем, дождь) — снять отдельно, когда появится выбор формата.

## 7. Расписание

Ритм: старт — по посту в день, потом 2–3 поста в неделю; лучшее время для русскоязычной аудитории — 19:00–21:00 по Москве, выходные — в 12:00. Закреп — до первого поста. Таверну (она пока некрасивая) в кадрах не показываем: пересняты уведомления, не брать для постов кадры `03`, `05`, `06`, `10`, `23`, пока таверна не перерисована.

| День | Посты |
|---|---|
| Д0 | закреп + 1 |
| Д1–Д3 | 2, 3, 4 |
| Д4–Д7 | 5, 6, 7, 8 |
| Д8–Д11 | 9, 10, 11, 12 |
| Д12–Д15 | 13, 14, 15, 16 |
| Д16–Д19 | 17, 18, 19, 20 |
| Д20–Д22 | 21, 22 |

Можно ставить отложенную публикацию (Telegram: кнопка отправки → «Запланировать»).

## 8. Как это публиковать

1. Создать канал (публичный, тип — «Канал»), название и @username из п. 2, описание из п. 3.
2. Загрузить аватар `logo_avatar_512.png`.
3. Опубликовать закреп (п. 4) и закрепить.
4. Постить по расписанию, подпись = текст из п. 5 вместе с файлом из заголовка.

Автопубликацию через Claude in Chrome делать только с явного «да» владельца и через его собственный вход: пароль, код и токены в чат не присылать.
