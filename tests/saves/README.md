# Золотые сейвы

Файлы `vX.Y.Z-<одиночка|кооп>-<карта>[-класс]-s<сид>.json.gz` — настоящие сейвы (то, что `saveGame` кладёт в localStorage,
и мир кооп-сервера `world.json`), записанные РАЗНЫМИ версиями игры. `tests/save-test.js` грузит каждый в текущий код.
Версии: 0.9.5, 0.9.14, 0.10.0, 0.10.25, 0.10.50, 0.10.70, 0.10.90, 0.10.110. Режимы/карты: луга, лес, степь, болото, зима, горы, побережье;
сложность «спокойная» и «выживание»; герои: воин, маг, лучник, разбойник, паладин (уровни 9–15, гильдии, оружейная); три мира кооп.

## Как пополнить (после обновления формата или к каждой «круглой» версии)
```
git worktree add --detach D:/wt-saves-gen/vX.Y.Z <коммит версии>
node tools/gen-golden-save.js --root D:/wt-saves-gen/vX.Y.Z --out tests/saves/vX.Y.Z-solo-meadow-s11.json.gz --seed 11 --minutes 25
```
Параметры — в шапке `tools/gen-golden-save.js` (`--biome`, `--size`, `--diff`, `--hero КЛАСС --level N --guilds 1`, `--kind coop`).
`tools/gen-golden-all.sh` пересобирает всю библиотеку целиком (около 6 минут; нужны worktree версий).
Генератор берёт игру из указанной копии (её же `server/simhost.js`) и бота из текущего `tests/lib/sim.js`.

Новый сейв кладут РЯДОМ со старыми, старые не заменяют: смысл библиотеки — старые форматы.
Имя должно начинаться с `vВЕРСИЯ-`, мир кооп-сервера содержит `-coop-` (грузится тем же путём, что и на сервере).
